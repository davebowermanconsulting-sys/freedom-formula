## How to apply the page specs in Wix
1. Open the Malang site in the Wix Editor in Chrome (you log in yourself).
2. Start a **local** Claude Code session with Claude in Chrome enabled.
3. Ask it to work from `pages/*.md`, one section at a time, showing each change before saving.
4. Do the desktop pass, then a separate mobile-editor pass.
5. **Save → Preview. Do not Publish.**
